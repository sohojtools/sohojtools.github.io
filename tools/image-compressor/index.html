ইমেজ কমপ্রেশন কী?

ইমেজ কমপ্রেশন ছবির ফাইল সাইজ কমায়, যাতে ছবি সহজে আপলোড, শেয়ার বা সংরক্ষণ করা যায়।

Target size কীভাবে কাজ করে?

Target size হলো সর্বোচ্চ কাঙ্ক্ষিত ফাইল সাইজ। Tool ছবির quality সামঞ্জস্য করে সেই সীমার মধ্যে আনার চেষ্টা করে। ছবি আগে থেকেই ছোট হলে quality অপ্রয়োজনীয়ভাবে কমানো হয় না।

ভালো ফলাফলের জন্য

  • খুব ছোট target দিলে quality কমতে পারে
  • বড় ছবির ক্ষেত্রে processing কিছুটা সময় নিতে পারে
  • Target-এর মধ্যে থাকা ছোট ছবিকে অপ্রয়োজনীয়ভাবে compress করা হবে না
